# v0.1.1 — figure audit + real-data validation

Patch release on the v0.1.0 manifest. Fixes the figures that the
post-release audit (`docs/FIGURE_AUDIT.md`) flagged as 🔴 broken or
🟡 weak, refreshes the global plotting theme, adds a one-shot
data-fetch bootstrap, and weaves the empirical findings (with
literature anchors) into the manuscript abstract, §3, §4, §5, §6,
§8, §9, §10.

## Figure fixes (closes the FIGURE_AUDIT.md verdicts)

- **F3 / F4 / F5** — replaced the badly-scaled efficiency-rate
  formula. The new figures plot $1/\widehat\nu(x)$ with the BRE
  asymptotic floor $1/(N^\alpha - 1)$ overlaid; crude-MC rate
  $\mu/(1-\mu)$ shown for comparison. F4 now correctly shows
  heterogeneous-$\alpha$ designs *above* the common-$\alpha$ curve
  (the BRE bound is controlled by $\alpha_{\min}$).
- **F6** — replaced the "all-tied pilot rules" non-result with a
  surrogate-kind benchmark. Loss surrogate $\widehat\rho^2 \approx
  0.005$; $X_{(2)}$-shift and max-coord surrogates push
  $\widehat\rho^2$ above 0.6. **Closes handoff Q1**.
- **F7** — fixed a Neyman-allocation bias: the previous version
  conflated allocation and estimator weights, producing a biased
  $\widehat\mu$. The new version uses stratum-probability weights
  for the estimator and Neyman weights for allocation only; all
  three variants agree on $\widehat\mu$ within sampling SE.
- **F19** — replaced the binary single-seed coverage panel with
  $R = 40$ replications across an AR(1) $\rho$ sweep. Headline
  finding: iid bootstrap coverage drops to $\sim 0.4$ at $\rho =
  0.9$ while block / stationary stay near 0.85. **Closes handoff Q4**.

## Global theme refresh

- Full four-edge spines on every panel.
- Larger fonts: title 15pt, axes 13pt, ticks 12pt, legend 11pt.
- Thicker default lines (2pt) and markers (6pt); legends have a
  faint frame for readability on dense backgrounds.

## Self-contained figure tex files

- Every `docs/report/figures/<basename>.tex` is now a full
  `\begin{figure}\centering\includegraphics\caption{insight}\label{...}\end{figure}`
  block.
- Section files do `\input{figures/<basename>.tex}` once.
- Long captions carry the diagnostic *insight* inline (e.g. F3
  caption explicitly states the BRE floor; F19 caption states the
  iid-bootstrap failure at high $\rho$).
- Nine new figures (F2--F7, F9, F10, F19) added to §3 / §5 / §9.
